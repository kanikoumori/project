# CMS Project

## 概要

卒業研究として開発するCMS（コンテンツ管理システム）です。

ユーザーがノーコードでWebサイトを作成・公開できることを目的としています。

---

## 使用技術

* XAMPP
PHPを実行するための開発環境です。ApacheやPHPなどが含まれており、ローカル環境でWebアプリを動かすことができます。

* Laravel 12
Webアプリケーションを効率よく開発するためのPHPフレームワークです。ルーティングや認証、データベース操作などを簡単に実装できます。

* PHP 8.2
サーバー側で処理を行うプログラミング言語です。ログイン処理やデータベースとの連携などを担当します。

* PostgreSQL 16
データを保存・管理するリレーショナルデータベースです。ユーザー情報やサイト情報、ページ情報などを保存します。

* Laravel Breeze
ログイン・新規登録などのユーザー認証機能を簡単に導入するためのLaravel公式スターターキットです。

* Blade
Laravelのテンプレートエンジンです。HTMLとPHPを組み合わせて、画面（View）を作成します。

* Vite
JavaScriptやCSSを高速にビルド・配信する開発ツールです。開発時の変更を素早くブラウザへ反映できます。

* JavaScript
Webページに動きを付けるプログラミング言語です。ボタン操作やドラッグ操作、リアルタイムな画面更新などを実現します。

* CSS
Webページの見た目を整えるためのスタイルシート言語です。色やレイアウト、文字サイズなどを設定します。

* GitHub
ソースコードを管理・共有するサービスです。複数人での共同開発やバージョン管理に利用します。

* Render
Webアプリケーションをインターネット上に公開（デプロイ）するためのクラウドサービスです。完成したシステムを利用者が閲覧できるようにします。

## 主な機能

### 実装中

* ユーザー認証
本システムでは、ユーザー認証機能を実装し、
登録したアカウントでログインすることで、
各ユーザーが自身のサイトを管理・編集できるようにします。

* サイト作成
ユーザーは新しいWebサイトを作成できます。
サイト名やテーマを設定し、編集画面から自由にデザインや内容を変更できます。
作成したサイトは保存・プレビュー・公開が可能です。

* ページ作成
ユーザーは作成したサイト内に複数のページを追加できます。
各ページにはタイトルや内容を設定し、編集・保存・プレビュー・公開を行うことができます。

* ブロック管理
ユーザーはページ内に見出し、文章、画像、動画、ボタンなどのブロックを追加できます。
各ブロックは編集・削除・並び替え・サイズ変更が可能で、ノーコードでページを作成できます。

* プレビュー
ユーザーは作成・編集中のサイトを公開前に確認できます。
実際の表示イメージを確認し、必要に応じて修正した後に公開することができます。

### 今後実装予定

* 自動保存
ユーザーが編集した内容は一定時間ごと、または変更時に自動で保存されます。
保存ボタンを押し忘れた場合でも、編集内容を保持し、途中から作業を再開できます。

* テーマ変更
ユーザーはサイトのテーマを変更し、
デザインやレイアウトを簡単に切り替えることができます。
テーマを変更しても、作成したページやコンテンツは保持されます。

* 公開機能
ユーザーは作成したサイトを公開できます。
公開前にはプレビューで内容を確認でき、公開後は利用者がWebブラウザから閲覧できるようになります。
また、必要に応じて非公開へ戻すことも可能です。

* アクセス解析
ユーザーは管理画面からサイトのアクセス状況を確認できます。
閲覧数や人気ページなどを分析し、サイト運営の参考にすることができます。

* フィードバック
利用者はサイトに対する感想や改善点などのフィードバックを送信できます。
送信された内容は管理者が確認し、サイトの改善に活用できます。


```bash

```

```bash
php artisan serve
npm run dev
```
