##ログイン機能

###新規アカウント作成

####概要
アカウントを持っていない場合は入力内容を入れて新規で作成し、ログイン状態でダッシュボードに移動する

####入力内容

-ユーザー名
-メールアドレス
-パスワード
-パスワード（確認）

#####パスワードの条件

8文字以上　英数字記号可能

####入力後

新規作成ボタンを押す
押すとユーザーが入力した
-名前
-メールアドレス
-パスワード
-パスワード確認がサーバーに送信される



#####phpで入力チェックを行う

名前が空でないか
メールアドレス形式か
メールアドレスが重複していないか
パスワードが8文字以上か
パスワード確認と一致するか

#####エラーが出た場合

エラーがあれば登録を中止し、入力画面へ戻してエラーメッセージを表示する
エラーが出る条件
パスワードが未入力のとき
パスワード確認欄が未入力のとき
パスワードと確認用パスワードが一致しないとき
パスワードが8文字未満のとき

#####phpでの入力画面が通った場合

エラーがなければパスワードをハッシュ化したものを保存し、usersテーブルにユーザー情報を登録する.
登録したユーザーをログイン状態にし、ダッシュボードへ移動する



###ログイン機能

####概要

ログイン認証成功後、LaravelはセッションIDを生成し、認証済みユーザーの情報をセッションに保存する。ブラウザにはCookieとしてセッションIDを保持させ、以降のアクセス時に送信されたセッションIDを基にユーザーを識別することでログイン状態を維持している。また、認証後はセッションIDを再生成し、セッション固定攻撃を防止している。

####入力内容

-メールアドレス
-パスワード

####ログイン状態を保持

毎回メールアドレスとパスワードを入力せずともログインすることができる


####入力完了

ログインのボタンを押す

####Laravel認証処理実行

LoginRequestで入力チェック

#####エラーが出る場合

メールアドレスが未入力のとき
パスワードが未入力のとき
メールアドレスが登録されていないとき
パスワードが間違っているとき

####usersテーブル照合

入力されたメールアドレスを使い入力されたパスワードをハッシュ化し、DBに保存されているハッシュを比較する

####認証成功

ハッシュ値が一致したら新しいセッション制作し、サーバー側に情報を保存することでログイン維持したままダッシュボードに移動する
・セッションがあることで誰が利用しているか分かり、ログイン維持できる



###パスワードを忘れた方はこちら

####概要

パスワードを忘れた場合、登録済みメールアドレス宛にパスワード再設定用URLを送信する。利用者はURLから新しいパスワードを設定できる。再設定時にはトークン認証を行い、本人確認後に users テーブルのパスワード情報を更新する。

####入力

ユーザーが登録済みのメールアドレスを入力して送信する

####userテーブルを確認する

userテーブルで入力されたメールアドレスが存在するか確認

#####エラーが出る場合

メールアドレスが未登録のとき

####パスワードリセット用トークンを作成

ランダムな文字列を生成し、パスワード再設定用トークンとして保存します

####リセットメールを送信

ユーザーへメールを送ります。
メール内にはURLが含まれます。
ーザー本人しかメールを受信できないため、本人確認の役割もあります。

####メール内のURLをクリック

ユーザーがメールのリンクを開くと、
-新しいパスワード
-新しいパスワード（確認）
を入力する画面が表示されます。

####新しいパスワードを登録

問題なければ、ハッシュ化して users テーブルのパスワードを更新します。

#####エラーが出る場合

パスワード再設定用のURLが期限切れのとき
新しいパスワードが条件を満たしていないとき
新しいパスワードと確認用パスワードが一致しないとき


####パスワード変更完了

古いパスワードが使えなくなり、新しいパスワードでしかログインできなくなった。
